Этот файл читается Claude Code автоматически. Здесь — что за проект, что где лежит,

## О проекте
- **Партнёрский лендинг ГектарЪ** — программа заработка агентов на продаже земельных участков.
- **Live:** https://partners.gektar.expert
- Репозиторий самодостаточный: клон = корень проекта.

## Стек и команды
- **Vite + React 19 + TypeScript + Tailwind CSS v3 + framer-motion + shadcn/ui** (react-router-dom v7).
- `npm install` → `npm run dev` (http://localhost:5173) → `npm run build` (в `dist/`).
- **Перед коммитом всегда:** `npx tsc --noEmit -p tsconfig.app.json && npm run build`.
- После правок: `git add -A && git commit && git push origin main` → **автодеплой на reg.ru** (см. ниже). Прод обновляется сам за 1–2 мин.

## Дизайн-система — СОБЛЮДАТЬ во всех правках

Направление: **glassmorphism + аэрофото + зелёная палитра** (собрано из референсов
SolarSphere / Agrone / GreenSpace / Adaline). Спокойный премиум, много воздуха,
крупная типографика, мягкие анимации. НЕ перегружать эффектами.

**Палитра:**
- `#1c5238` — глубокий лес (основной тёмно-зелёный, текст-акцент, тёмные кнопки)
- `#2fae5b` — свежий зелёный (CTA, акценты, eyebrow-подписи)
- `#3ec469` — яркий зелёный (акценты на тёмном фоне)
- `#16201a` — чернила (основной текст)
- `#f4f1ea` — кремовый (карточки, светлые секции)
- `#0f1d15` — тёмно-зелёный фон (секция бонусов)
- `#c9a978` — золото (ценники в бонусах)
- стекло (frosted) — фирменный приём

**Шрифты** (все с кириллицей, импорт в `src/index.css`):
- **Manrope** — UI и body (базовый шрифт)
- **Unbounded** — акцентный display, класс `.font-display` (крупные заголовки, цифры)
- **Fragment Mono** — микро-подписи, класс `.mono` (eyebrow-лейблы в стиле Adaline)

**Утилиты в `src/index.css`** (использовать их, не изобретать заново):
`.glass` / `.glass-soft` / `.glass-dark` (стеклянные поверхности), `.hectare-grid`
(фоновая «гектарная» сетка), `.hero-shadow` (тень текста на фото), `.kenburns`
(медленный зум фото), `.font-display`, `.tight` (плотный трекинг), `.mono`.

**Приёмы:** плавающая стеклянная навигация-пилюля; full-bleed аэрофото в hero с
затемнением и вотермарком «ГЕКТАРЪ»; стеклянные карточки статистики; кнопки —
зелёные пилюли со стрелкой в кружке; кадастровые планы как «герои» карточек участков
(signature — «Земля, которую видно сверху»); мотив гектарной сетки на фоне секций.

**Анимации (framer-motion):** `fadeUp` c blur-in при появлении секций; параллакс и
зум hero на скролле; лёгкое «парение» стеклянных карточек; заголовок hero выезжает
по строкам с блюром; hover-подъём карточек. Уважать `prefers-reduced-motion`.

    Footer.tsx, SocialLinks.tsx, CountUp.tsx, ui/ (shadcn)

  .htaccess               SPA-fallback для reg.ru (Apache) — ОБЯЗАТЕЛЕН для чистых путей
  sitemap.xml, robots.txt, blog/ (posts.json + картинки блога)
.github/workflows/deploy.yml   авто-деплой

**Данные проектов-участков** (названия, локации, ссылки на Я.Диск, кнопки) — прямо в
`src/pages/*Page.tsx`. Карточки на главной — массив `lands` в `HomePage.tsx`.

## Деплой
- **push в `main`** → GitHub Actions собирают и заливают по FTP на reg.ru (`.github/workflows/deploy.yml`).
- Нужны 4 секрета репо: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `FTP_SERVER_DIR`.
- Хостинг reg.ru — обычный виртуальный, панель ISPmanager. Подробности в `HANDOFF.md`.

## Важные правила и подводные камни
- **Роутер = BrowserRouter.** Внутренние ссылки БЕЗ `#` (напр. `/tula`). Прямые заходы работают только благодаря `public/.htaccess` — на любом Apache/reg.ru он обязателен.
- **`/blog`** конфликтует с реальной папкой `/blog/` (там данные) → в `.htaccess` спец-правило; внутренние ссылки ведут на `/blog/` (со слэшем).
- **3D-туры НЕ в git** (большие, ~200 МБ) — лежат на хостинге в `/tour/kostomarovo/` и `/tour/silverlake/`. Большие медиа-ассеты не коммитить.
- **Картинки:** класть в `public/images`, оптимизировать (jpg, не тяжёлый png). Новые визуалы можно генерировать ИИ-инструментами и оптимизировать перед коммитом.
- **ContactForm.tsx:** токен Telegram-бота и ссылка Google Sheets зашиты в клиентском коде (видны в браузере). Это не «секрет» в смысле git, но при смене владельца их меняют — см. `HANDOFF.md`.
- **Проверять всё на превью** (`npm run dev`) и на мобильной ширине перед пушем.

## Типовые задачи
- **Изменить контент участка** → соответствующий `src/pages/<Регион>Page.tsx` (Тула — инлайн; Тверь/Крым/Москва — данные в их файле, вёрстка в `LandPageTemplate.tsx`).
- **Текст/цифры на главной** → массивы `lands` / `reasons` / `stats` / `bonuses` вверху `HomePage.tsx`.
- **Добавить новый участок** → добавить в `lands` (HomePage) + создать страницу + маршрут в `App.tsx` + строку в `sitemap.xml`.
- **SEO-теги страницы** → вызов `usePageMeta(title, description)` в начале компонента.
