# ГектарЪ — партнёрский сайт

Партнёрский лендинг ГектарЪ. Живёт на https://partners.gektar.expert

**Стек:** Vite + React 19 + TypeScript + Tailwind + framer-motion.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Деплой

Push в ветку `main` → GitHub Actions собирают и заливают сайт по FTP на reg.ru
автоматически (`.github/workflows/deploy.yml`).
